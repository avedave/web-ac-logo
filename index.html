Web-Logo Quick Start Guide

Welcome to WEB-LOGO!

This is a zero-dependency, local-first client implementation of Logo programming language. You can control the turtle avatar on the canvas by typing commands in the console (CMD) or executing whole scripts (FILE).

Quick Commands Sheet:

  • FD 100 — Move Forward by 100 units
  • BK 50 — Move Backward by 50 units
  • RT 90 — Rotate Right by 90 degrees
  • LT 45 — Rotate Left by 45 degrees
  • PU / PD — Pen Up (lift) or Pen Down (lower to draw)
  • SETPC red / SETPC #ff00ea — Set pen line color
  • SETPS 5 — Set pen stroke thickness to 5px
  • CS — Clear Canvas screen and reset turtle coordinates
  • REPEAT 4 [ FD 80 RT 90 ] — Repeat block to draw a square

Tips for Premium Drawing:

  1. Animations: Set the speed slider to "Slow" or "Medium" to watch the turtle animate and rotate smoothly as it constructs your vectors! Set to "0 (Instant)" for large fractal algorithms.
  2. Multi-language: You can type commands in any supported language (English, French, German, Spanish, Italian, Polish). Go to Settings to translate the whole UI and Cheatsheet!
  3. Saved files: Use Local Browser Storage to store your drafts, and try out the built-in Presets in the left sidebar to see what's possible (Koch curves, trees, spirals!).
